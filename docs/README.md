## 📝 Contribuir a la Documentación

Para añadir o actualizar documentación:

1. Seguir el formato Markdown estándar
2. Usar títulos descriptivos y jerarquía clara
3. Incluir ejemplos de código cuando sea relevante
4. Añadir enlaces a recursos externos si es útil
5. Mantener TOC (tabla de contenidos) actualizado
6. Usar lenguaje claro y conciso
7. Revisar ortografía y gramática

### Estructura de Documento Tipo

```markdown
# Título del Documento

Breve descripción del propósito.

## 📋 Tabla de Contenidos

- [Sección 1](#sección-1)
- [Sección 2](#sección-2)

## Sección 1

Contenido...

## Sección 2

Contenido...

## 🔗 Referencias

- [Link externo](https://example.com)

---

**Última actualización:** [Fecha]
```

## 🎨 Convenciones de Estilo

- **Emojis:** Usar para secciones principales (📋 📝 🔧 ⚠️ ✅)
- **Code blocks:** Especificar lenguaje (`bash`, `php`, etc.)
- **Alertas:** Usar blockquotes con emoji para advertencias
- **Links:** Relativos para docs internas, absolutos para externas
